# survival-ocean
## 일시정지와 저장

- 오른쪽 위 잠수함 카드 옆의 `⏸ 정지` 버튼 또는 `P` / `Esc`로 멈추고 계속할 수 있습니다.
- 다른 앱이나 탭으로 전환하거나 창이 포커스를 잃으면 자동으로 멈춥니다. 복귀 후 직접 계속하기를 누릅니다.
- 일시정지 화면의 `저장하기` 또는 `저장 후 계속하기`로 수동 저장합니다. 저장 성공 메시지를 확인한 뒤 종료하세요.
- 재접속 시 시작 화면의 `이어하기`를 누릅니다. 저장이 있으면 Enter로도 이어할 수 있습니다.
- 저장 항목: 구역과 위치, 체력, 레벨, 강화와 미선택 강화 화면, 가방, 광물, 광석 재생 시간, 수룡 체력·갈무리·부활 시간, 전리품.
- 일반 물고기와 총알은 저장하지 않습니다. 이어할 때 물고기를 다시 배치하고 2초간 캐릭터를 보호합니다. 수룡의 진행 중 공격 예고는 취소하며 다음 공격 전 최소 3초를 제공합니다.
- 저장 슬롯은 하나이며 같은 기기·같은 브라우저에서 유지됩니다. 새 게임으로 시작해도 이전 저장은 유지되지만, 다음 저장 시 덮어씁니다. 브라우저 데이터를 지우면 저장도 삭제됩니다.
- 일시정지나 게임 종료 중에는 재생·회복·부활 시간이 흐르지 않습니다. 일반 플레이는 수동 저장이며 제작·장착 시에는 자동 저장합니다. 기기 간 동기화는 지원하지 않습니다.

```sh
npm run build
```

## 모바일 조준

- 발사 버튼 위쪽의 `🎯 조준`을 한 번 터치하면 이동이 멈추고 조준선과 슬로모션이 켜집니다.
- 조이스틱으로 방향을 맞추고 발사 버튼을 누르면 정밀 사격 후 조준이 해제됩니다.
- 조준 버튼을 다시 누르면 발사하지 않고 취소합니다. 계속 누르고 있을 필요가 없습니다.
- 연사 도중 조준을 켜면 연사를 멈춥니다. 발사 버튼을 다시 터치하면 정밀 사격합니다.
- 일시정지·강화 선택·이어하기 때 조준은 해제됩니다. PC에서는 기존대로 Z키를 누르고 조준할 수 있습니다.

## 잠수함 제작 상점

처음에는 5등급 일반 잠수함에 탑승합니다. 상점에서는 아래 재료를 소모해 제작하고 바로 탑승합니다.

| 잠수함 | 등급 | 제작 재료 |
| --- | --- | --- |
| 일반 잠수함 | 5등급 | 기본 보유 |
| 튼튼한 검정 잠수함 | 4등급 | 부싯돌 10개 |
| 불속성 잠수함 | 3등급 | 루비 5개 + 부싯돌 10개 |
| 얼음속성 잠수함 | 3등급 | 사파이어 5개 + 부싯돌 10개 |
| 전기속성 잠수함 | 3등급 | 토파즈 6개 + 부싯돌 10개 |
| 메탈 잠수함 | 2등급 | 다이아몬드 7개 |
| 아기 드래곤 잠수함 | 1등급 | 수룡의 머리뼈 1개 + 수룡의 비늘 2개 |

- 오른쪽 위 카드에 잠수함 외형·등급·이름을 표시합니다. 카드 왼쪽에 상점, 그 아래에 일시정지 버튼이 있습니다.
- 코인 획득·구매를 제거했습니다. 기존 광물 인벤토리와 수룡 전리품에서 재료를 사용합니다.
- 상점에 보유 재료와 제작에 필요한 수량을 표시합니다. 한 재료라도 부족하면 제작할 수 없습니다.
- 이미 제작한 잠수함은 추가 재료 없이 교체합니다. 상점이 열려 있는 동안 게임은 멈춥니다.
- 제작·장착은 진행 상태와 함께 즉시 저장합니다. 저장에 실패하면 제작과 모든 재료 차감을 취소합니다.
- 부싯돌 장갑, 루비 불꽃, 사파이어 얼음 결정, 토파즈 번개 코일, 다이아몬드 금속 장갑, 수룡 뿔·비늘·꼬리 등 외형을 구분했습니다. 속성별 전투 능력은 별도로 추가하지 않았으며 이동 속도는 동일합니다.
- 기존 저장은 계속 사용할 수 있습니다. 이전 산호 탐사호는 검정 잠수함, 심해 수호호는 얼음속성 잠수함, 황금 수룡호는 메탈 잠수함으로 보유·탑승 정보를 옮깁니다. 광물과 수룡 전리품은 그대로 유지합니다.
