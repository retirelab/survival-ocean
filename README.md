# survival-ocean
## 일시정지와 저장

- 화면 오른쪽 위 구석의 `⏸ 일시정지` 버튼 또는 `P` / `Esc`로 멈추고 계속할 수 있습니다.
- 다른 앱이나 탭으로 전환하거나 창이 포커스를 잃으면 자동으로 멈춥니다. 복귀 후 직접 계속하기를 누릅니다.
- 일시정지 화면의 `저장하기` 또는 `저장 후 계속하기`로 수동 저장합니다. 저장 성공 메시지를 확인한 뒤 종료하세요.
- 재접속 시 시작 화면의 `이어하기`를 누릅니다. 저장이 있으면 Enter로도 이어할 수 있습니다.
- 저장 항목: 구역과 위치, 체력, 레벨, 강화와 미선택 강화 화면, 가방, 광물, 광석 재생 시간, 수룡 체력·갈무리·부활 시간, 전리품.
- 일반 물고기와 총알은 저장하지 않습니다. 이어할 때 물고기를 다시 배치하고 2초간 캐릭터를 보호합니다. 수룡의 진행 중 공격 예고는 취소하며 다음 공격 전 최소 3초를 제공합니다.
- 저장 슬롯은 하나이며 같은 기기·같은 브라우저에서 유지됩니다. 새 게임으로 시작해도 이전 저장은 유지되지만, 다음 저장 시 덮어씁니다. 브라우저 데이터를 지우면 저장도 삭제됩니다.
- 일시정지나 게임 종료 중에는 재생·회복·부활 시간이 흐르지 않습니다. 자동 저장 및 기기 간 동기화는 지원하지 않습니다.


## 모바일 조준

- 발사 버튼 위쪽의 `🎯 조준`을 한 번 터치하면 이동이 멈추고 조준선과 슬로모션이 켜집니다.
- 조이스틱으로 방향을 맞추고 발사 버튼을 누르면 정밀 사격 후 조준이 해제됩니다.
- 조준 버튼을 다시 누르면 발사하지 않고 취소합니다. 계속 누르고 있을 필요가 없습니다.
- 연사 도중 조준을 켜면 연사를 멈춥니다. 발사 버튼을 다시 터치하면 정밀 사격합니다.
- 일시정지·강화 선택·이어하기 때 조준은 해제됩니다. PC에서는 기존대로 Z키를 누르고 조준할 수 있습니다.

## 잠수함과 상점

- 게임을 새로 시작하면 **일반 · 노랑 탐험호**에 탑승합니다.
- 오른쪽 위 카드에 현재 잠수함 그림, 등급, 이름을 표시합니다. 카드 왼쪽에 상점, 그 아래에 일시정지 버튼이 있습니다.
- 수조에 물고기를 넣으면 가방 수량 1마리당 10코인을 얻습니다. 기존 레벨업 규칙도 유지됩니다.
- 일반: 무료 / 희귀 산호 탐사호: 300코인 / 영웅 심해 수호호: 900코인 / 전설 황금 수룡호: 2,400코인.
- 희귀·영웅·전설의 이동 속도는 기본보다 각각 10%·20%·30% 빠릅니다.
- 구매하면 바로 탑승하며, 보유 잠수함은 무료로 다시 탑승할 수 있습니다. 상점을 열면 게임이 멈춥니다.
- 구매·장착 즉시 진행 상태를 저장합니다. 저장 실패 시 거래는 취소되고 코인은 차감하지 않습니다. 일반 플레이 중 얻은 코인은 기존 저장 버튼으로 저장하세요.
- 예전 저장 파일도 읽을 수 있으며, 잠수함 정보가 없으면 일반 잠수함과 0코인으로 이어합니다.
