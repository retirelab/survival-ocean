- 파일은 `public/assets/audio/`에 보관하며 GitHub Pages 배포에 포함됩니다.

## 헬리코프리온의 둥지

- 지하세계 2층 오른쪽 끝의 노란 빛 통로로 들어갑니다. 둥지 왼쪽 위 노란 출입구로 나가면 지하세계 2층으로 돌아갑니다.
- 들어가는 순간 헬리코프리온 보스전과 보스 BGM(serrated_mandibles.mp3)이 시작됩니다. 토벌하거나 둥지를 나가면 구역 곡으로 돌아갑니다.
- 체력 2000, 공격력 30. 멀리 있으면 붉은 예고선 방향으로 매우 빠르게 돌진하고, 가까이 있으면 아래턱을 위아래로 휘두릅니다.
- 돌진은 예고 순간의 주인공 위치를 지나 벽까지 이어집니다. 돌진 경로에 B 폭탄이 있으면 폭발하여 헬리코프리온에게 500 피해를 주고 잠시 휘청이게 합니다.
- 언덕 위 폭탄 4개는 터진 뒤 20초가 지나면 다시 생깁니다. 헬리코프리온은 토벌 5분 뒤 부활하며, 둥지를 나가도 남은 체력은 유지됩니다.

## 일시정지와 저장

- 오른쪽 위 잠수함 카드 옆의 `⏸ 정지` 버튼 또는 `P` / `Esc`로 멈추고 계속할 수 있습니다.
- 다른 앱이나 탭으로 전환하거나 창이 포커스를 잃으면 자동으로 멈춥니다. 복귀 후 직접 계속하기를 누릅니다.
- 일시정지 화면의 `저장하기` 또는 `저장 후 계속하기`로 수동 저장합니다. 저장 성공 메시지를 확인한 뒤 종료하세요.
- 재접속 시 시작 화면의 `이어하기`를 누릅니다. 저장이 있으면 Enter로도 이어할 수 있습니다.
- 저장 항목: 구역과 위치(빙하수 골짜기~열수분출공층 포함), 체력, 레벨(Lv.40 확장 여부 포함), 수룡 통로 개방 여부(수룡을 처음 토벌하면 영구 개방), 강화와 미선택 강화 화면, 가방, 광물, 광석 재생 시간, 수룡 체력·갈무리·부활 시간, 헬리코프리온 체력·부활 시간·폭탄 재생 시간, 전리품.
- 일반 물고기와 총알은 저장하지 않습니다. 이어할 때 물고기를 다시 배치하고 2초간 캐릭터를 보호합니다. 수룡의 진행 중 공격 예고는 취소하며 다음 공격 전 최소 3초를 제공합니다.
- 저장 슬롯은 하나이며 같은 기기·같은 브라우저에서 유지됩니다. 새 게임으로 시작해도 이전 저장은 유지되지만, 다음 저장 시 덮어씁니다. 브라우저 데이터를 지우면 저장도 삭제됩니다.
- 일시정지나 게임 종료 중에는 재생·회복·부활 시간이 흐르지 않습니다. 일반 플레이는 수동 저장이며 제작·장착 시에는 자동 저장합니다. 기기 간 동기화는 지원하지 않습니다.

## 모바일 조준

- 발사 버튼 위쪽의 `🎯 조준`을 한 번 터치하면 이동이 멈추고 조준선과 슬로모션이 켜집니다.
- 조이스틱으로 방향을 맞추고 발사 버튼을 누르면 정밀 사격 후 조준이 해제됩니다.
- 조준 버튼을 다시 누르면 발사하지 않고 취소합니다. 계속 누르고 있을 필요가 없습니다.
- 연사 도중 조준을 켜면 연사를 멈춥니다. 발사 버튼을 다시 터치하면 정밀 사격합니다.
- 일시정지·강화 선택·이어하기 때 조준은 해제됩니다. PC에서는 기존대로 Z키를 누르고 조준할 수 있습니다.

## 잠수함 제작 상점

처음에는 5등급 일반 잠수함에 탑승합니다. 상점에서는 아래 재료를 소모해 제작하고 바로 탑승합니다.

| 잠수함 | 등급 | 제작 재료 |
| --- | --- | --- |
| 일반 잠수함 | 5등급 | 기본 보유 |
| 튼튼한 검정 잠수함 | 4등급 | 부싯돌 10개 |
| 불속성 잠수함 | 3등급 | 루비 5개 + 부싯돌 10개 |
| 얼음속성 잠수함 | 3등급 | 사파이어 5개 + 부싯돌 10개 |
| 전기속성 잠수함 | 3등급 | 토파즈 6개 + 부싯돌 10개 |
| 메탈 잠수함 | 2등급 | 다이아몬드 7개 |
| 아기 드래곤 잠수함 | 1등급 | 수룡의 머리뼈 1개 + 수룡의 비늘 2개 |

- 오른쪽 위 카드에 잠수함 외형·등급·이름을 표시합니다. 카드 왼쪽에 상점, 그 아래에 일시정지 버튼이 있습니다.
- 코인 획득·구매를 제거했습니다. 기존 광물 인벤토리와 수룡 전리품에서 재료를 사용합니다.
- 상점에 보유 재료와 제작에 필요한 수량을 표시합니다. 한 재료라도 부족하면 제작할 수 없습니다.
- 이미 제작한 잠수함은 추가 재료 없이 교체합니다. 상점이 열려 있는 동안 게임은 멈춥니다.
- 제작·장착은 진행 상태와 함께 즉시 저장합니다. 저장에 실패하면 제작과 모든 재료 차감을 취소합니다.
- 부싯돌 장갑, 루비 불꽃, 사파이어 얼음 결정, 토파즈 번개 코일, 다이아몬드 금속 장갑, 수룡 뿔·비늘·꼬리 등 외형을 구분했습니다. 잠수함별 전투 특성은 아래와 같으며 이동 속도는 동일합니다.
- 기존 저장은 계속 사용할 수 있습니다. 이전 산호 탐사호는 검정 잠수함, 심해 수호호는 얼음속성 잠수함, 황금 수룡호는 메탈 잠수함으로 보유·탑승 정보를 옮깁니다. 광물과 수룡 전리품은 그대로 유지합니다.

## 잠수함 전투 특성

| 잠수함 | 전투 특성 |
| --- | --- |
| 일반 | 기본 총알, 특수 능력 없음 |
| 튼튼한 검정 | 물고기에게 피격되는 순간부터 5초간 방어 배율 2배. 다시 피격되면 5초로 갱신 |
| 불속성 | 불덩이 명중 시 5초간 매초 고정 화상 피해 2. 재명중은 지속 시간만 갱신 |
| 얼음속성 | 고드름 명중 시 3초간 물고기 이동 속도 50% 감소 |
| 전기속성 | B키 또는 전기일격 버튼으로 반경 140의 살아 있는 물고기를 5초 마비. 재사용 대기 30초 |
| 메탈 | 기본 방어 배율 4, 노란 관통 레이저를 끊어서 발사 |
| 아기 드래곤 | 스페이스바 또는 모바일 발사 버튼을 누르는 동안 긴 푸른 브레스를 연속 발사 |

- 잠수함 방어 배율은 기존 방어 강화 배율과 곱합니다. 메탈의 기본 방어 4배는 기존 강화가 2배라면 총 8배가 됩니다.
- 전기일격 버튼은 전기속성 잠수함에서 표시되며 가까운 대상이 있고 쿨다운이 끝났을 때 밝게 켜집니다. 대상이 없으면 대기시간을 소모하지 않습니다.
- 마비는 HP를 줄이거나 수집 가능한 기절 상태로 바꾸지 않습니다. 마비 중 이동과 접촉 공격만 멈춥니다. 화상 피해는 마비 중에도 적용됩니다.
- 체력이 0이 되면 기존과 같이 8초간 기절하여 수집할 수 있습니다. 화상·감속·마비는 이때 해제합니다.
- 화상·감속·마비 및 잠수함 방어·전기 대기시간은 활성 플레이 시간 기준이며 조준 슬로모션 때문에 길어지지 않습니다. 일시정지·상점·강화 메뉴에서는 시간이 멈춥니다.
- 전기일격 쿨다운과 방어 버프 남은 시간도 저장합니다. 물고기는 기존 저장 정책대로 다시 배치합니다.
- 아기 드래곤 브레스는 일반 난사 불가 강화가 적용돼도 길게 눌러 사용할 수 있습니다. 손을 떼거나 일시정지하면 즉시 멈춥니다.
